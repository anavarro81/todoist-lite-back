# Requerimientos. 

## Search
- Permite buscar tareas por su nombre o descripción. 
- Si se incluye varias palabras en la busqueda busca todas. 
- Muestra un listado de las 3 últimas tareas creadas o modificadas. 

## Inbox
- Permite ver todas las tareas asignadas a un usuario (token).
- Se mostrará un *contador de taras*
- El usuario podra editar las tareas o completarlas. 

## Today
- El usuario podra ver las tareas vencidas y las del día actual. 
- Overdue tasks are highlighted.
- Tasks can be completed directly from the Today view.

## Upcoming
- The user can see tasks grouped by date for the next days.
- The user can reschedule tasks via drag & drop (future feature).


## Labels
- The user can assign one or more labels to a task.
- The user can filter tasks by label.

## Listado de tarea
- De cada tarea sea mostrará como mínimo su nombre y un chekbox para completarla.

## Etiquetas
- Boton etiquetas
    - Listado de todas las etiquetas personalizado del usuario.     
        - Cada etiqueta tiene un color, nombre y un contador de las tareas que tienen esa tarea. 
        - Al hacer clic en una etiqueta
    - Botón para agregar tareas
        - Añadir etiqueta:
          - Nombre (obligatorio)
          - Color (opcional) (por defecto gris)
          - toggle para agregar a favoritos (por defecto: false)

## Proyectos
- Listado de proyectos. Como máximo cinco. Si hay mas, se botón mas. 
- Añadir proyecto
    - Nombre (obligatorio)
    - Color (opcional) (por defecto gris)
    - toggle para agregar a favoritos (por defecto: false)

### Detalle de proyecto

- Se muestra un *listado* con las tareas del proyecto
- Las tareas se puede agrupar
